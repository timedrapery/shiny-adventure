# SN 45.2 Translation Notes

This document records the source and editorial decisions for
[SN 45.2: Upaḍḍha Sutta](sn45-2-upaddha-sutta.md).

## Source Base

- Primary source: SuttaCentral Bilara Mahāsaṅgīti root text, segment IDs
  `sn45.2:1.1`–`sn45.2:4.4`.
- Canonical reader source: <https://suttacentral.net/sn45.2/pli/ms>.
- Control surfaces: the existing eightfold-path terminology in MN 117 and the
  seclusion/fading/quenching/relinquishment sequence in MN 118.

## Governing Decisions

- `kalyāṇamittatā` is `good friendship`, with the adjacent forms translated as
  `good companionship` and `good fellowship`. Keeping all three makes the
  emphatic social breadth audible without turning one repeated root into three
  unrelated ideas.
- `upaḍḍha` is `half`; `sakala` is `the whole`. The correction is kept as a
  direct exchange rather than softened into “important.”
- `brahmacariya` is `spiritual life`, the existing repository default.
- `bhāveti` / `bahulīkaroti` is `develops` / `keeps developing`. This preserves
  both cultivation and repetition in ordinary speech.
- `vivekanissitaṁ virāganissitaṁ nirodhanissitaṁ vossaggapariṇāmiṁ` is
  `supported by seclusion, fading, and quenching, maturing in relinquishment`.
  Each path factor receives the complete line even where the root file uses
  peyyāla abbreviation.
- The closing causal claim is not reduced to “friends help.” It specifically
  presents the Buddha as the good friend through whom beings subject to birth,
  aging, death, and distress can be freed from them.

## Wording Revision: 2026-11-08

- By explicit editorial decision, this translation follows Dhammarato's
  teaching usage, recorded in the
  [talk transcripts profile](../dhammarato-talk-transcripts-profile.md).
- `samādhi` and its compounds now use `unification of mind`, or the compact
  `unification` inside compounds (for example `right unification of mind`,
  `born of unification`), in place of `composure`.
